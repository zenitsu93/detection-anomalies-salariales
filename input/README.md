# Données de démonstration

Les trois CSV sont des données synthétiques issues de la génération, confirmées comme telles par le porteur du projet. Ils sont conservés tels que fournis, sans recalcul. Encodage cp1252, séparateur point-virgule, salaires en milliers de MAD par an.

`python src/generate_sources.py` remplace les trois fichiers. Le générateur peut produire un marché différent du jeu conservé ; les CSV versionnés font référence pour reproduire les résultats fournis.
